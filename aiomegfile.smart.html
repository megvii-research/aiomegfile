async aiomegfile.smart.smart_sync(src_path: str | PathLike, dst_path: str | PathLike, callback: Callable[[str, int], None] | None = None, followlinks: bool = True, callback_after_copy_file: Callable[[str, str], None] | None = None, force: bool = False, *, worker: int = -1) → None[source]

Sync file or directory to the destination path.

Note

When the parameter is file, this function behaves like smart_copy.

If file and directory of same name and same level, sync considers it as file first.

Parameters:

  • src_path – Given source path.

  • dst_path – Given destination path.

  • callback – Called periodically during copy with source path and bytes written.

  • followlinks – Whether to follow symbolic links.

  • callback_after_copy_file – Called after each source file is processed, including files skipped because the destination is already up to date. The input parameters are src file path and dst file path.

  • worker – Maximum number of concurrent workers for copy tasks.

  • force – Sync file forcible, do not ignore same files.

Raises:

FileNotFoundError – If source path does not exist.
